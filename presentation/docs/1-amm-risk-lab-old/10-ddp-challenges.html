Distributed Data Parallel (DDP) Training Challenges

Profiling Results: The Underutilization Problem

GPU Analysis

  • Small model size (hidden dim and heads) → compute underutilization
  • Tried increasing batch size
  • Hit GPU memory limits
  • Memory-bound rather than compute-bound

CPU Analysis

  • Mostly data loading only
  • Diminishing returns with more DataLoader workers
  • Massive CPU cores left idle
  • Opportunity for hybrid compute!
