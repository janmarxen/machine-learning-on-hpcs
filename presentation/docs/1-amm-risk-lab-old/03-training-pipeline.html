Training Pipeline Strategy

Training Pipeline: Pretraining → Finetuning

🏭 Pretraining Phase

  • 📊 Data size: ~500GB distributed HDF5
  • Pools: +1M pools from multiple AMMs
  • 📈 Features: ~100 hourly time series features
  • 🎯 Goal: Learn general AMM liquidity patterns
Foundation Model

🎯 Finetuning Phase

  • 📊 Data size: Few MB per pool
  • Pools: Single pool of interest
  • 📈 Features: Same ~100 features
  • 🎯 Goal: Adapt to specific pool behavior
Specialized Model
