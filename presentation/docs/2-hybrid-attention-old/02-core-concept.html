Why Hybrid Attention? The Resource Utilization Gap

Current State: Massive Underutilization

🖥️ CPU Resources

  • Hundreds of GB RAM vs 16-80GB GPU
  • Many cores idle during training
  • DataLoader workers show diminishing returns
  • Excel at irregular, sparse computation patterns (divergence)

Hybrid Solution: Smart Resource Partitioning

🎯 Perfect Use Case: 1-2 CPU + 1 GPU

  • PCIe bandwidth for transfers
  • No multi-GPU competition
  • CPU not overloaded with data loading
CPU (128 cores)
├── 32 cores → Data Loading
└── 96 cores → Sparse Attention (Batch dimension flattened → huge sparse matrices)

GPU
├── Dense Attention (FlashAttention)
├── Feed-forward layers
└── Parameter updates
