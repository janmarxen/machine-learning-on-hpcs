Hybrid Inference (Existing Work)

Limitations for Inference

  • Latency critical → communication overhead hurts
  • Small batch sizes (1-32 examples). Overhead plays a significant role
  • KV cache introduces additional synchronization needs
  • Per-token generation speed matters most

Hybrid Training (My Focus)

Why Training is Better

  • Large batch sizes → communication overhead amortized
  • Throughput over latency optimization
  • More batches = more opportunities
  • Memory scaling enables bigger models
  • No KV cache limitations
