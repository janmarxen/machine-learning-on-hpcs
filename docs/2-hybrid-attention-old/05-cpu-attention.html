CPU Block Sparse Attention Mechanism

"How should CPU compute attention for multiple examples?"
❌ Independent Examples vs ✅ Block-Diagonal Matrices

❌ Independent Examples

for batch in batches: Q, K, V = batch.split() attn = softmax(Q @ K.T) @ V send_to_gpu(attn)

Performance Issues:

  • ❌ Cache thrashing between examples, Poor memory locality
  • ❌ PCIe congestion from multiple transfers (from pipelining examples)

✅ Block-Diagonal Matrices

# Stack all batches into block-sparse-diagonal Q_big = block_sparse_diag(sp_Q₁, sp_Q₂, ..., sp_Qₙ) K_big = block_sparse_diag(sp_K₁, sp_K₂, ..., sp_Kₙ) V_big = block_sparse_diag(sp_V₁, sp_V₂, ..., sp_Vₙ) # Single large sparse computation attn_all = sparse_softmax(Q_big @ K_big.T) @ V_big send_to_gpu(attn_all) # Single transfer

Performance Benefits:

  • ✅ Sequential memory access (CPU optimized) of sparse elements, Cache-friendly
  • ✅ BLAS/MKL optimization, AVX-512 vectorization across examples
  • ✅ Single PCIe transfer (minimized latency)
