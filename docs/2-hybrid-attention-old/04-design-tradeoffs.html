Design Tradeoffs & Implementation Considerations

How do we balance CPU and GPU workloads for optimal performance?

🚀 Minimize Setup

  • • Smaller data, less accumulation → setup overhead more noticeable
  • • Single large > multiple small. Adapt learning rates (local minima)
  • • Need to efficiently serialize (sparse) attention outputs + new batch

⚖️ Synchronization

  • • Batch sizes need careful tuning
  • • Should converge simultaneously
  • • Hardware-dependent sweet spot. Software optimization needed.

⚙️ Static Partitioning

  • • No fancy load balancing
  • • Avoid CPU-GPU communication
  • • Predictable distribution

🎯 Application Dependent

  • • Disk vs Memory loading
  • • Data type: Video/Text/Audio
  • • Effect on PCIe vs Data Loading overhead
