CPU Block Sparse Attention: The Key Optimization

❌ Independent Examples vs ✅ Block-Diagonal Matrices

❌ Naive Approach

for batch in batches: Q, K, V = batch.split() attn = softmax(Q @ K.T) @ V send_to_gpu(attn)

Problems:

  • ❌ Cache thrashing between examples
  • ❌ Multiple PCIe transfers (latency)
  • ❌ No vectorization across batch

✅ Block-Diagonal Optimization

# Stack into block-sparse-diagonal Q_big = block_diag(sp_Q₁, ..., sp_Qₙ) K_big = block_diag(sp_K₁, ..., sp_Kₙ) V_big = block_diag(sp_V₁, ..., sp_Vₙ) # Single large sparse computation attn = sparse_softmax( Q_big @ K_big.T) @ V_big send_to_gpu(attn) # Single transfer

Benefits:

  • ✅ Sequential memory access (cache-friendly)
  • ✅ BLAS/MKL + AVX-512 vectorization
  • ✅ Single PCIe transfer (minimal latency)

🚀 Result: CPU sparse computation becomes competitive with GPU for irregular patterns
