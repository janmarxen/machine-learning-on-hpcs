Hybrid CPU/GPU Attention

Leveraging Heterogeneous Compute for Transformer Training

💡 Core Hypothesis

CPU: Sparse Attention
GPU: Dense Attention + Feed-forward
Result: Full Resource Utilization

✓ Why This Works

  • CPU: 1024 GB vs GPU: 40GB RAM
  • CPU excels at sparse patterns
  • No PCIe bottleneck w/ example-batch-level and attention-level sparsity
CPU (128 cores)
├── 32 cores → Data Loading
└── 96 cores → Sparse Attention

GPU (A100)
├── Dense Attention (FlashAttention)
├── Feed-forward layers
└── Parameter updates
1:1 CPU:GPU Compute Ratio (No multi-GPU competition)
